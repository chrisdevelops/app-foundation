# Foundation specs

Save the exported specs here:

- `decision-summary.md`: the Electron App Foundation Decision Summary
- `token-profile-spec.md`: the Design Token Profile Spec

These are the source of truth. Wording changes only through an accepted ADR. In phase 0 the planner adds requirement IDs (for example `TOK-012`) to each requirement without changing its wording, and the human reviews them before spikes begin.
